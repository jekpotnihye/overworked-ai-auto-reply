A tiny program that writes one line of plain text — the funniest one-line
out-of-office auto-reply from an overworked AI agent finally taking a
vacation — to `/output/entry.txt`.

Run it with Node 22 or later:

```sh
node main.ts
```

It writes the auto-reply to `/output/entry.txt` and prints it to stdout.
